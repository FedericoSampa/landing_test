## Cómo trabajar

1. Pegá las imágenes en la carpeta correspondiente con esos nombres exactos.
2. Refrescá la pestaña del navegador (con `npm run dev` corriendo).
3. Si una imagen aparece rota / no carga, queda automáticamente el gradiente de placeholder.

¿Tenés una imagen con otro nombre? Cambiá el nombre del archivo, no el código.
